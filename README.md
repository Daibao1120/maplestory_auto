# 楓之谷自動補水

掛機時一直盯著遊戲畫面，補品快用完就自動打開妙妙補貨；血量異常或角色死亡就發警報。

> ⚠ **帳號風險**：用外部程式操作遊戲違反 Nexon 的服務條款，被偵測到有停權的可能。請自行評估。

---

## 圖形介面版（給朋友用：MapleAutoPot.exe）

不用裝 Python，下載一個 exe 就能用：到這個 repo 的 **Releases → latest** 下載 `MapleAutoPot.exe`，
放進一個新資料夾（設定、校正資料會存在 exe 旁邊）後雙擊執行。

1. 開遊戲、登入角色，視窗維持平常掛機的大小；現金欄裡要有妙妙。
2. 「設定」→ **第 1 步 自動校正**（約 1 分鐘，期間不要動滑鼠）。
3. **第 2 步 掃描妙妙商店**：程式自己把商品清單捲一遍，列出每一種商品 → 選「HP 補品／MP 補品」、
   快捷欄放在哪一格、要補到幾個 → 套用。任何妙妙商店裡的商品都可以。
4. （可選）**第 3 步 掃描背包**：勾要順便賣掉的東西（可以保留最上面幾組）。
5. 「監控」→ 先按 **試跑一次**（最後都按取消，不會真的買賣），沒問題再 **開始監控**。

遊戲被別的視窗蓋住也照常監控（背景截圖），不會把遊戲叫到前面；你正在用電腦時，一般補貨會等你停下來。
exe 是 GitHub 在 Windows 上自動打包的（`.github/workflows/build.yml`：跑完全部測試 → 打包 → 自我檢查）。
防毒軟體有時會誤判這類程式，要按「允許」。

## 它怎麼保護你不死

| 層級 | 偵測方式 | 動作 |
|---|---|---|
| 1. 數量不足 | 讀快捷欄上的數字（馴鹿奶、刨冰） | 低於門檻 → 補到目標數量 |
| 2. 數字讀不到 | 數字辨識失效時自動切換 | 每隔 N 小時定時補貨 |
| 3. 補品其實用完了 | 看 HP／MP 條：HP 一直低於 35%、MP 一直低於 8% | **立刻緊急補貨** |
| 4. 補了還是危險 | 緊急補貨 60 秒後還是很低 | 嗶嗶聲＋Discord 通知 |
| 5. 角色死亡 | HP 條歸零 | 警報，並停止所有自動操作 |
| 6. 補貨失敗 | 找不到按鈕、背包滿、楓幣不夠 | 關掉商店、重試；連續失敗 3 次就警報 |

其他防呆：

- **每一步都看畫面確認**才進行下一步，找不到就停下並關掉商店，不會亂點。
- **只賣白名單上的道具**，超級藥水、特殊藥水這些沒列的東西一律不碰。
- 數字辨識要**連續兩次一致**才採用；沒補貨卻變多、一次掉太多、位數突然變少，都視為讀錯並丟掉。
- 剛啟動就讀到很低的數字時，保守只買固定數量，不會一次買到上限。
- 你正在動滑鼠時，先延後一般補貨（緊急補貨不等）。
- 遊戲視窗被擋住或縮小時不做判斷，避免誤判成死亡。
- 視窗大小跟校正時不同會警告（座標會跑掉）。
- **緊急停止**：滑鼠甩到螢幕**左上角**，或按 **F12**。

## 安裝（第一次）

1. 安裝 Python 3.10 以上的 **64 位元**版本：https://www.python.org/downloads/ （安裝時勾選「Add python.exe to PATH」）。舊版 Python 可以留著不用移除。
2. 把這個資料夾放在任何地方，例如桌面。
3. 雙擊 **install.bat**：它會自動挑電腦上最新的 Python，在資料夾裡建立專用環境（`.venv`）並安裝套件，不會影響你其他 Python 專案。

## 自動校正（推薦，約 1 分鐘）

1. 遊戲在一般掛機畫面，視窗維持平常的大小，不要被其他視窗擋住。
2. 雙擊 **autocal.bat**，期間不要動滑鼠。程式會自己打開道具欄、妙妙商店、購買數量視窗（最後按取消，不會真的買），把需要的按鈕和區域全部存好。
3. 看到「✅ 自動校正完成」後，雙擊 **check.bat** 確認，再跑 **dryrun.bat** 試跑。

如果某一步失敗，失敗畫面會存在 `data/autocal_fail.png`，可以只用下面的手動方式重做那一項。

## 手動校正（自動校正失敗時才需要）

程式要先「認識」你的遊戲畫面：哪裡是血條、妙妙長怎樣、購買按鈕在哪。

1. 先把遊戲視窗調到你平常掛機的大小，**之後不要再改大小**。
2. 雙擊 **calibrate.bat**，照著畫面上的指示做。每一步程式會自動切到遊戲截圖，然後跳出框選視窗：
   - 先在整張畫面上**大概**框住目標，按 Enter
   - 再在放大圖上**精確**框住目標，按 Enter（框錯按 C 取消）
3. 最後會測試數字辨識：看一下快捷欄，數字對就直接按 Enter，不對就輸入正確數字（例：`4360 525`）。

校正完後雙擊 **check.bat**，會列出目前畫面認得哪些東西，並輸出標示圖 `data/check.png`。

某一項框錯，只要重做那一項就好：

```
py calibrate.py redo miaomiao
py calibrate.py redo hp_bar
```

## 試跑（強烈建議）

雙擊 **dryrun.bat**：完整走一次「開妙妙 → 找商品 → 輸入數量」，但最後一律按**取消**，不會真的買賣。
看它每一步有沒有點對。

## 開始使用

雙擊 **start.bat**。視窗會每分鐘顯示一次狀態，例如：

```
HP 100%｜MP 37%｜馴鹿奶 4360 個（每小時 960，約 4.5 小時用完）｜紅豆刨冰 525 個（每小時 118，約 4.4 小時用完）
```

| 熱鍵 | 功能 |
|---|---|
| F9 | 暫停 / 繼續 |
| F10 | 立刻補貨一次 |
| F12 | 結束程式 |

（熱鍵沒反應的話，對 start.bat 按右鍵 →「以系統管理員身分執行」。）

記錄檔：`data/autopot.log`

## 設定（config.yaml，用記事本打開）

- `buy.hp.target / buy.mp.target`：補貨時補到多少（預設 6750 / 850）
- `buy.*.refill_below`：剩多少就去補（預設 1500 / 200）
- `buy.*.fallback_buy`：數字讀不到時每次固定買多少
- `safety.timer_refill_hours`：數字讀不到時，幾小時補一次
- `notify.discord_webhook`：填 Discord Webhook 網址，警報會傳到你的手機
- `safety.hp_emergency`／`mp_emergency`：**一定要低於遊戲裡自動喝水的百分比**（例如遊戲設 50% 喝 HP，這裡就用 35%），否則正常喝水也會一直觸發
- `sell`：要賣的道具（白名單）

### 想順便賣掉雜藥水

1. 打開妙妙商店，右邊切到「消耗」，讓那個藥水出現在清單上。
2. 執行 `py calibrate.py sell sell_red_potion`，**只框道具名稱文字**（圖示上的數量會變，不要框到）。
3. 在 `config.yaml` 的 `sell:` 加上：

```yaml
sell:
  - template: sell_red_potion
    name: 紅色藥水
    keep_stacks: 0
  - template: sell_elixir
    name: 萬能療傷藥
    keep_stacks: 1      # 留一組
```

（萬能療傷藥賣價是 0 楓幣，賣掉只會空出格子。）

### 用 Discord 收警報

Discord 頻道 → 編輯頻道 → 整合 → Webhook → 新 Webhook → 複製網址，貼到 `notify.discord_webhook`。

## 常見問題

**數字一直讀不到？**
執行 **digits.bat**，輸入正確數字讓程式學習。數字變了之後多學幾次效果更好。
就算一直讀不到，程式還是會用「HP／MP 條＋定時補貨」保護你。

**改了視窗大小？**
重新執行 calibrate.bat。

**妙妙打不開？**
程式會重試 3 次；如果跳出提示框（例如點到別的道具），會停下並警報。用 `py calibrate.py redo miaomiao` 重新框妙妙圖示。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `run.py` | 主程式 |
| `calibrate.py` | 校正工具 |
| `config.yaml` | 設定 |
| `autopot/` | 程式本體（辨識、商店流程、安全判斷） |
| `assets/digits_base.npz` | 數字辨識的預設模板（從你的截圖做的） |
| `templates/` | 校正時存的按鈕／圖示 |
| `data/` | 校正資料、記錄檔 |
| `tests/` | 自動測試（`py -m pytest tests`） |
