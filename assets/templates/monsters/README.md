# 怪物模板（鱷魚 Croco）

把你自己從遊戲畫面裁下來的**鱷魚**截圖放在這個資料夾，`MonsterDetector` 會載入全部圖片做多模板比對。

## 命名與建議

- 檔名隨意，副檔名用 `.png`（也支援 jpg/bmp）。例如：`crocodile_1.png`、`crocodile_2.png`。
- **多補幾張不同狀態的鱷魚**能明顯提高命中率：
  - 不同**動作影格**（張嘴/閉嘴/眨眼/走動）。
  - 不同**面向**（左向、右向）——可直接把右向圖水平翻轉當左向模板。
  - 若背景差異大，裁**貼身一點**（減少背景干擾）。
- 模板請以「和實際遊戲相同的解析度」裁切；換解析度要重裁。

## 只鎖定鱷魚，別放寵物

- 畫面裡的**白色兔子是寵物**，會跟在角色附近移動——**不要**把兔子當模板。
- 模板比對只認「鱷魚外形」，所以兔子本來就不會被當成鱷魚；
  另外可在 `settings.yaml` 的 `vision.monster.roi` 限定平台帶狀搜尋區，進一步避免誤判。

## 命中（重要）

- 鱷魚 Lv32、命中需求約 44；你的 DEX/命中不足會 **miss**。請先確認角色命中夠，
  再讓腳本連續輸出，否則畫面上偵測到怪但實際打不中。

## 怎麼裁

用內建工具框選截圖存檔：

```powershell
python tools/capture_template.py --name crocodile_3 --out assets/templates/monsters
```

> 注意：本資料夾的實際圖片已被 `.gitignore` 排除（遊戲美術屬個人素材、不進版控），
> 只有這個 README 與 `.gitkeep` 會被追蹤。
